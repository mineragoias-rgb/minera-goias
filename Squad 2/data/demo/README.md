# MINERA Goiás — Dados Demo V2

Este pacote contém dados inteiramente sintéticos, criados apenas para desenvolver e testar o Motor Econômico-Energético antes da chegada das bases finais. Não representam produção, projetos, empresas ou intensidades reais.

## Conteúdo

- 8 minerais;
- 10 operações e 80 registros históricos de produção (2018–2025);
- intensidades energéticas, projetos, parâmetros anuais e regras de cenário;
- cenários: `conservador`, `referencia` e `expansao`.

Quando as bases reais chegarem, os CSV deverão ser substituídos mantendo a mesma estrutura de colunas.
